# Demo media

## What is in here

| File | What it is |
| --- | --- |
| `anatomy-light.svg`, `anatomy-dark.svg` | labelled diagrams of the grid's parts, generated by `tool/render_anatomy.dart` |
| `demo.gif` | a recording of the example app — **not committed yet**, see below |

The anatomy diagrams are diagrams, not screenshots. They name the parts and
show how they relate; they are drawn by a script so they can be regenerated
when the anatomy changes:

```bash
dart run tool/render_anatomy.dart
```

## Recording the demo GIF

The GIF has to be captured on a machine with the Flutter SDK, because it is a
recording of the real app. The README already references `docs/demo.gif`, so
dropping the file in makes it appear — no other change needed.

```bash
cd packages/lattice_flutter/example
flutter run -d macos        # or -d chrome, -d windows, -d linux
```

Then record the window. On macOS, `cmd+shift+5` records a selected region to
`.mov`; convert it with ffmpeg:

```bash
ffmpeg -i demo.mov \
  -vf "fps=18,scale=1200:-1:flags=lanczos,split[a][b];[a]palettegen[p];[b][p]paletteuse" \
  -loop 0 docs/demo.gif
```

Keep it under about 8 MB so GitHub renders it inline rather than making people
click through.

### What to show, in order

The demo is more convincing if it shows the things a `DataTable` cannot do.
Roughly 25 seconds:

1. **Scroll hard through the 20,000 rows.** The point is that it does not
   stutter and the frozen `#` column stays put.
2. **Click the `Latency` header twice** — ascending, then descending. Then
   ctrl-click `Service` to show a second sort level appearing with its
   numbered arrow.
3. **Type in the search box.** Search runs per keystroke over every column;
   let the row count in the footer fall as you type.
4. **Turn on "Group by service".** Collapse and expand a group so the counts
   and the per-group averages are visible.
5. **Double-click a Latency cell, type `-5`, press Enter.** The edit is
   rejected in place with its message. Correct it to a real number and watch
   the row move if a sort is active.
6. **Drag-select a block of cells** and press ctrl/cmd+C, then show the
   "N lines copied" snackbar.
7. **Drag a column edge** to resize, and double-click the edge to reset it.
8. **Switch the system appearance to dark** if your recorder allows it — the
   grid follows the Material theme.

### A still image instead

If a GIF is too much, a PNG of the example app at
`docs/screenshot-light.png` and `docs/screenshot-dark.png` works; add them to
the README the same way the anatomy diagrams are added, with a `<picture>`
element so each one shows in the matching GitHub theme.
