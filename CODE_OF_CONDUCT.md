# Code of conduct

## The short version

Be decent. Assume the person on the other side is trying to help and is short
on time. Critique code, not people.

## What is expected

- Give feedback on the work: what is wrong, why it matters, what would be
  better. "This is wrong" without a reason is not review.
- Accept that maintainers may decline a contribution. Scope is a real
  constraint, and a "no" is not a judgement of you.
- Remember that English is not everyone's first language, and that a terse
  message is usually haste rather than hostility.

## What is not acceptable

Harassment, insults, or personal attacks; sexualised language or imagery;
publishing anyone's private information; sustained disruption of a discussion;
or deliberately pushing a contributor out of the project.

## Reporting

Report conduct issues privately to the maintainer via
[a GitHub security advisory](https://github.com/Dhairya-007/lattice/security/advisories/new),
which is the only private channel this repository has. Reports are read by the
maintainer only and will be acted on in confidence.

Maintainers may edit, hide or remove contributions that violate this policy,
and may block accounts that keep doing so. Enforcement starts with a warning
except where the behaviour is severe enough that it should not.

## Scope

This applies in issues, pull requests, discussions, commit messages and code
review in this repository.
